# Social Express

Sistema de gestão com dashboard para provas, retiradas, devoluções, resultados financeiros, contas e agenda.

## Desenvolvimento

```bash
npm install
npm run dev
```

## CRM Comercial

Pipeline de contatos com valor potencial, ganho/perda e análise por traje.

1. `npm run dev`
2. Abra **/crm**
3. Use **Registrar conversa**, **Trajes e valores** e **Análise de valores**
4. Formulário público: **/captura**

Guia: [`docs/CRM-FACIL.md`](docs/CRM-FACIL.md)

## Build

```bash
npm run build
npm run preview
```
